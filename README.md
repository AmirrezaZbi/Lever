# Lever

Bodyweight endurance and back-friendly core training, as an installable web app.

Open the site on your phone and add it to your home screen:
- iPhone: Safari → Share → Add to Home Screen
- Android: Chrome → ⋮ → Install app

Everything is stored on the device. Use History → Save backup to keep a copy.

To ship an update, replace `index.html` and bump `VERSION` in `sw.js`.
